PokerB — Spielen
================================================================

Auf dem Desktop liegen zwei Verknüpfungen:

  • "PokerB 6-max spielen"      → 6-max gegen 5 Bots
                                   Browser: http://127.0.0.1:8000
  • "PokerB Heads-Up spielen"   → 1-gegen-1 + Claude-Coach
                                   Browser: http://127.0.0.1:8001

DOPPELKLICK genügt — der Browser öffnet sich automatisch.
Beide können gleichzeitig laufen (verschiedene Ports).

BEENDEN: das schwarze Fenster schließen (oder darin Strg+C).

GEGNER: die Engine-Bots — sofort und zuverlässig. Sie spielen
dieselbe Engine, die auch das GLM-Brain steuert: also dasselbe
Strategie-Niveau, nur ohne Wartezeit pro Zug.

WENN EIN START FEHLSCHLÄGT: das Fenster bleibt offen und zeigt die
Meldung. Häufigste Ursache: der Port ist noch belegt, weil ein altes
Fenster nicht geschlossen wurde — dann das alte Fenster schließen und
erneut starten.

(Manueller Start, falls nötig — im Projektordner:
   python -m pokerbot.web.six_server --open --port 8000
   python -m pokerbot.web.server     --open --port 8001 )
